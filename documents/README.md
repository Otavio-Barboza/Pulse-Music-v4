# Descrição documents


## Obejetivos:

- Manter maior praticidade e compreensão do código;
- Melhorar visualização e compreensão de estruturas, fluxos e operações do código;
- Tornar mais fácil compreensão para quem desconhece o código entender e conhecer as necessidades de cada operação;


## Como é separado o conteúdo em documents/ ???

1. **lyrics/**
    - Conteúdos relacionados aos processos de obtenção de letras musicais, cache de letras e gerecnciamento de traduções das letras.

2. **metadata/**
    - Conteúdo gerenciado nos JSONs: como, porque e o que é salvo em cada um utilizado.

3. **pipeline/**
    - Fluxo, estrutura e operação geral do pipeline, constando suas dependências diretas, arquivos e códigos necessários para funcionar.

4. **playlists/**
    - Operação do CRUD das playlists e gerenciamento dos dados de personalização.

5. **reproduction/**
    - Processo de reprodução, dependências e lógica aplicada.

6. **scanner/**
    - Fluxo de operação;
    - Gerenciamento dos dados e integração com pipeline;
    - Tomadas de decição e processos automatizados.


## Descrições gerais:

1. **md/**
    - arquivos .md esecíficos para um processo ou funcionalidade descrevendo as situações conforme os itens acima.

2. **README.md**
    - Arquivo geral apresentando estrutura, conceitos, informações gerais daquele processo como um todo.
