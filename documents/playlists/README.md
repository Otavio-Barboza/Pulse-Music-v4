# Ordem e Fluxo de Execuções do CRUD de Playlists


## CRUD: Create (criar), Read (ler), Update (atualizar) e Delete (excluir).


### CREATE: Criação das playlist, desde a interação do front-end com o back-end na criação.
    Descrições em: create.md;


### READ: Leitura, envolvendo a exibição das playlists em grid e carregamento individual de cada playlist.
    Descrições em: read.md;


### UPDATE: Edição das playlist pós serem criadas.
    Descrições em: update.md;


### DELETE: Processo de deletar playlists e suas execuções de dados.
    Descrições em: delete.md;
